# Development Guide

## Requirements

Initial target environment:

- PHP 8.4+
- MySQL or MariaDB
- Composer
- Apache or Nginx

## Local setup

Development setup instructions will be added as the application bootstrap is implemented.

Never commit `.env`, passwords, API keys, SMTP credentials, private license keys or production database exports.

## Workflow

All implementation work should be tied to an issue and delivered through a dedicated branch and pull request.
