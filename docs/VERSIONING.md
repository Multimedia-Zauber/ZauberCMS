# Versioning

ZauberCMS plans to use Semantic Versioning.

During pre-alpha development, versions may begin at `0.x.y`.

- Patch: fixes and small compatible changes
- Minor: new compatible functionality
- Major: incompatible changes or stable major releases

Planned milestones:

- `0.1.x` Foundation
- `0.2.x` Administration
- `0.3.x` Content
- `0.4.x` Extensibility
- `0.5.x` Operations and licensing infrastructure
- `1.0.0` First stable production release
