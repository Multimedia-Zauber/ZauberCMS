# Contributing to ZauberCMS

ZauberCMS uses an issue-driven development workflow.

## Workflow

1. Open or select an issue.
2. Create a dedicated branch from `main`.
3. Keep changes focused on the issue.
4. Test the change locally.
5. Open a pull request referencing the issue.
6. Review before merging.

## Branch naming

Use short, descriptive branch names such as:

- `feature/web-installer`
- `feature/theme-system`
- `fix/login-rate-limit`
- `docs/installation-guide`

## Pull requests

Pull requests should explain what changed, why it changed, how it was tested and which issue they close.
