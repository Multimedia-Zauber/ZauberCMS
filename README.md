# ZauberCMS

ZauberCMS is a modular, source-available PHP CMS by **Multimedia Zauber**.

The goal is to provide a reusable CMS foundation for modern websites and customer projects, with a stable core, installable modules, themes, and customer-specific extensions.

> Status: Early development / pre-alpha

## Planned architecture

- CMS core
- Web installer
- Authentication, users, roles and permissions
- Page and navigation management
- Media library
- Theme system
- Module/plugin system
- Multilingual content
- SEO tools
- Forms and SMTP notifications
- Backups, logs and update center
- Commercial licensing for business use

## Licensing

ZauberCMS is intended to be source-available. Private/non-commercial and commercial usage rights will be defined in the project license. Commercial deployments will require an appropriate ZauberCMS license unless explicitly stated otherwise.

## Development workflow

Development follows an issue-driven workflow:

1. Create or select an issue
2. Create a dedicated branch
3. Implement and test the change
4. Open a pull request
5. Review and merge into `main`
